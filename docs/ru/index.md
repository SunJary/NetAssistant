## Почему NetAssistant

- **Высокая производительность**: асинхронный рантайм Rust + Tokio, запуск < 100 мс, потребление памяти < 20 МБ, миллионы одновременных подключений
- **Создан для отладки**: от разработки сетевых приложений до отладки железа и встраиваемых систем — весь цикл проверки связи
- **Кроссплатформенность**: полная поддержка Windows, Linux и macOS, нативные сборки для x64 и ARM64
- **Открытый код и бесплатность**: распространяется по лицензии Apache-2.0, вклад приветствуется

Подробнее — в разделе [Возможности](/en/features); чтобы начать, прочитайте [Руководство](/en/guide/). Сравнение с NetAssist и похожими инструментами — в [таблице сравнения](/en/comparison).
