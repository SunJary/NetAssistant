# FAQ

## Поддерживает ли macOS классический сетевой отладчик NetAssist?

Следует различать два похожих по названию инструмента: **NetAssistant** — кроссплатформенный инструмент, описанный на этом сайте, — поддерживает macOS, Windows и Linux с нативными сборками x64 и ARM64, а классический **NetAssist** с похожим названием выпускается только для Windows.

Для отладки TCP/UDP на Mac или в Linux просто используйте **NetAssistant** — он работает так же, как знакомые вам отладочные ассистенты; скачать его можно на [странице загрузки](/ru/download), а [начало работы](/en/guide/) и полную [таблицу сравнения](/en/comparison) смотрите в соответствующих разделах.

## В чём разница между NetAssistant и NetAssist?

Это **разное программное обеспечение** с похожими названиями. NetAssist — закрытый инструмент только для Windows; NetAssistant — открытый (Apache-2.0) кроссплатформенный инструмент на Rust, поддерживающий Windows/Linux/macOS на x64 и ARM64, с четырьмя TCP-декодерами для «склейки» пакетов и встроенным высоконагруженным тестированием (QPS и задержки p50/p95/p99). Полную таблицу сравнения см. в [разделе сравнения](/en/comparison).

| | NetAssistant | NetAssist |
| ---- | ---- | ---- |
| Платформы | Windows / Linux / macOS (x64 + ARM64) | Только Windows |
| Открытый код | ✅ Apache-2.0 | ❌ Закрытый код |
| TCP-декодеры («склейка» пакетов) | Необработанные / по строкам / префикс длины / JSON | Ограниченно |
| Высоконагруженное тестирование TCP/UDP | ✅ QPS + p50/p95/p99 | ❌ |

## Как установить NetAssistant через winget?

В Windows рекомендуемый способ — winget (с автоматическими обновлениями):

```bash
winget install SunJary.NetAssistant
```

Для обновления используйте:

```bash
winget upgrade SunJary.NetAssistant
```

Другие варианты установки — на [странице загрузки](/ru/download).

## Есть ли deb-пакет для Linux?

Да. Предоставляются пакеты **deb**, **AppImage** и **tar.gz** (для x86_64 и aarch64):

- **deb** (рекомендуется): для Debian/Ubuntu и производных — `sudo apt install ./netassistant-linux-x86_64.deb` разрешает зависимости автоматически; работает на Ubuntu 22.04 и новее
- **AppImage**: портативный, работает сразу — отлично подходит для Fedora/Arch и других дистрибутивов; при первом запуске нужен `sudo apt install libfuse2`
- **tar.gz**: распакуйте и запускайте, требуется GTK3 (`sudo apt install libgtk-3-0`)

Ссылки для скачивания — на [странице загрузки](/ru/download#linux).

## NetAssistant бесплатен и с открытым исходным кодом?

Да. NetAssistant распространяется под лицензией **Apache-2.0**, все функции бесплатны. Исходный код размещён на [GitHub](https://github.com/SunJary/NetAssistant) — вклад приветствуется.

## Как бороться со «склейкой» пакетов TCP?

NetAssistant поставляет четыре TCP-декодера, которые автоматически разбивают поток байтов, так что считать байты вручную не нужно:

1. **Необработанные данные** — отображаются в порядке поступления
2. **Разделение по строкам** — по символу новой строки
3. **Префикс длины** — по полю длины в заголовке
4. **JSON** — по каждому завершённому JSON-объекту

См. [руководство по отладке TCP/UDP](/en/guide/tcp-udp).
